# Python
Este material presenta una guía básica y práctica de Python, pensada para quienes inician en programación, ciencia de datos o automatización. Incluye ejemplos ejecutables y explicaciones progresivas.

📌 1. ¿Qué es Python y dónde se usa?

Lenguaje multipropósito usado en:

Desarrollo web

Ciencia de datos (NumPy, Pandas, Matplotlib)

Automatización

Aplicaciones en la nube

Scripting y software general

📌 2. Google Colab

Se explica su uso como entorno interactivo en la nube, atajos de teclado y tipos de celdas (código y Markdown).

📌 3. Tipos de datos y variables

Numéricos (int, float)

Booleanos

Strings y uso de input()

📌 4. Operadores

Aritméticos, comparación, lógicos, asignación

Identidad (is) y pertenencia (in)

Orden lexicográfico

📌 5. Estructuras de control

Condicionales if / elif / else

Bucles for y while

📌 6. Estructuras de datos

Listas (modificación, slicing, métodos)

Matrices (listas anidadas)

Strings como secuencias

Tuplas (inmutables)

Conjuntos y operaciones (unión, intersección, etc.)

Diccionarios (keys, values, items)

📌 7. Funciones

def, return, argumentos por defecto

Funciones que procesan listas

Composición

Lambdas y funciones internas

📌 8. Clases y objetos

Declaración de clases

__init__, __str__

Métodos, uso de self

Modificación y eliminación de atributos y objetos
